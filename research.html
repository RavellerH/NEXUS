Retrieval Methods

How the system finds the right chunks. The most impactful layer to get right first.

TL;DR Use hybrid retrieval (BM25 + dense + RRF) as the default. Add ColBERT late-interaction only if you have a latency budget and high-recall requirements. Never use dense-only in production corpora with exact identifiers (codes, IDs, names).

Reranking

The fastest quality multiplier. Retrieve wide (top 20–50), rerank to tight (top 3–5).

Graph RAG

When entities, relationships, and multi-hop reasoning matter more than chunk similarity.

TL;DR Microsoft GraphRAG: +50–70% comprehensiveness on global/thematic queries — but $33K indexing cost for 5GB with GPT-4. LightRAG is 100× cheaper and nearly as good for most use cases. Use graph when your queries span entities across many documents.
System Query types it wins Indexing cost Self-hostable
Microsoft GraphRAG Global/thematic, cross-document synthesis $$$$ (GPT-4 extraction) Yes
LightRAG Best value Global + local; dual-level search 100× cheaper than GraphRAG Yes
LlamaIndex Property Graph Structured entity retrieval, traversal Medium Yes
Graphiti (temporal) Agent memory, time-aware queries Medium Yes
Vector RAG (baseline) Local factual lookups, single-hop Cheap Yes
When to use Graph RAG: Cross-document entity questions ("which suppliers are connected to this PO?"), hierarchical navigation (plant → unit → equipment), global queries requiring synthesis across hundreds of documents, agent memory with time-ordered episode recall.

When NOT to: Simple single-document factual lookup, latency-sensitive paths, when corpus is <1,000 documents.

Minimal Viable Stack (Any Domain)

1. Fixed-size chunking (512 tokens, 10% overlap) 2. Embedding: text-embedding-3-large (commercial) or BGE-M3 (self-hosted) 3. Vector store: pgvector or ChromaDB (dev) → Qdrant (production) 4. Hybrid retrieval: BM25 + dense + RRF 5. Reranking: MixedBread base-v2 6. Framework: LlamaIndex Upgrade path: → Add Contextual Retrieval (immediate quality boost, +35% failure reduction) → Switch to hierarchical indexing (for multi-section documents) → Add Mem0 or Zep (for multi-turn agents) → Add Graph RAG (for entity relationships and global queries)

Technology Maturity Matrix

Production readiness as of 2026. "Stable" means battle-tested at scale. "Research" means promising but not production-grade.

Hybrid Retrieval (BM25 + Dense)

Stable
De facto standard. All major vector DBs support it natively (Weaviate, Qdrant) or via external BM25 (Elasticsearch, OpenSearch). No production reason to use dense-only.

Cross-encoder Reranking

Stable
Proven quality multiplier. MixedBread, BGE, Cohere all have production-ready APIs and self-hosted options. Standard in any quality-focused pipeline.

Contextual Retrieval

Stable
Anthropic Sep 2024 technique: prepend chunk-level context before embedding. Well-benchmarked (35–67% failure reduction). Production-ready with any LLM.

LlamaIndex / LangGraph

Stable
Both are production-grade with extensive adoption. LlamaIndex leads for RAG; LangGraph for stateful agents. LangGraph 0.2+ has stable API.

Qdrant / pgvector

Stable
Both in broad production use. Qdrant 1.10+ stable. pgvector + pgvectorscale closes the performance gap vs. purpose-built databases for <100M vectors.

Mem0 / Zep Memory

Growing
Both have production-grade managed and self-hosted options. Mem0 widely integrated. Zep+Graphiti gaining enterprise adoption for temporal agent memory.

LightRAG / Graph RAG

Growing
Microsoft GraphRAG production-ready but expensive. LightRAG emerging fast. LlamaIndex PropertyGraph stable. Real production deployments increasing in 2025–2026.

BGE-M3 Tri-mode

Growing
Unique: one model for dense + sparse + ColBERT. Increasingly used in production. Sparse and multi-vector index support varies by vector DB.

Multimodal Embeddings (Cohere v4)

Growing
Cohere embed-v4 is the most production-ready multimodal embedding model. GPT-4o embeddings maturing. Use cases: engineering drawings + text retrieval.

DSPy Optimization

Emerging
Powerful for prompt optimization but observability, cost tracking, and deployment tooling explicitly listed as roadmap gaps. Not yet suitable for ops-heavy production.

Haystack v2 Pipelines

Growing
Declarative YAML-serializable pipelines with best-in-class token efficiency. Strong in European enterprise. Less ecosystem adoption than LlamaIndex/LangChain.

Agentic RAG (multi-step)

Emerging
ReAct + tool use + RAG loops have strong research backing. Production deployments increasing but reliability at scale (error recovery, cost) still an open problem.
● Stable — battle-tested, use in production without hesitation ● Growing — proven results, some rough edges in ops/tooling ● Emerging — strong promise, evaluate carefully before committing ● Research — not production-ready
