Deployment

Online (Default)

git clone [private repo]
cp .env.example .env
# edit .env: JWT_SECRET, admin credentials
docker-compose up -d
# Ollama auto-pulls qwen2.5:7b + multilingual-e5-large
# ~5.6 GB download on first run
Reference spec: DigitalOcean Singapore · 16 GB RAM · 8 vCPU · ~$96/mo

Offline / Air-Gapped

# On internet-connected machine:
./scripts/package-models.sh
# produces nexus-models.tar + nexus-images.tar

# Transfer to air-gapped site, then:
docker load -i nexus-images.tar
docker run --rm -v nexus_ollama:/root/.ollama \
  alpine tar -xf /mnt/nexus-models.tar -C /
docker-compose -f docker-compose.yml \
  -f docker-compose.offline.yml up -d
No internet required after initial package preparation

Hybrid Query Routing

Dense embeddings cannot reliably distinguish AT-201 from AT-202. The hybrid router uses FTS5 for exact alphanumeric identifiers and ChromaDB for natural language queries.

graph TD Q[User query] --> ROUTE{Contains alphanumeric
tag or code?} ROUTE -->|YES - AT-201, CBL-001-HV, PO-2024| FTS[SQLite FTS5
exact search
100% precision] ROUTE -->|NO - natural language| SEM[ChromaDB
semantic search
top-k cosine similarity] FTS --> MERGE[Merge + deduplicate
FTS results rank above semantic] SEM --> MERGE MERGE --> RB[Response Builder
Qwen2.5-7B] 
EXACT_PATTERN = re.compile(r'\b[A-Z]{1,4}-\d{3,4}[A-Z]?\b|\bCBL-\w+\b|\bPO-\d+\b')

def route_query(query_text: str) -> str:
    if EXACT_PATTERN.search(query_text):
        return "fts"   # precision-first: AT-201, PO-2024-003
    return "semantic"  # recall-first: natural language queries

Chunk Metadata Schema

Every chunk stored in ChromaDB carries this metadata. Also written to SQLite FTS5 for hybrid search.

{
    "chunk_id":         str,   # SHA256 of content + source_file (no timestamp — deduplication key)
    "source_file":      str,   # Original filename
    "source_type":      str,   # "whatsapp" | "pdf" | "excel" | "docx" | "pid" | "eml"
    "project_id":       str,
    "authority_level":  int,   # 1–5; lower = higher authority
    "author":           str | None,  # WhatsApp and email
    "timestamp":        str,   # ISO 8601; document date or message date
    "section_title":    str | None,
    "instrument_tags":  list[str] | None,  # P&ID tags: ["AT-201", "FT-101"]
    "ingested_at":      str,   # ISO 8601; when indexed
}
